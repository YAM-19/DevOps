# Software Development Life Cycle (SDLC)

## What Is SDLC?

The Software Development Life Cycle (SDLC) is a structured process used to plan, design, develop, test, and deploy high-quality software.

## Purpose of SDLC

- Meet customer requirements.
- Improve software quality.
- Reduce development errors.
- Define project scope and objectives.
- Deliver software efficiently.

## Phases of SDLC

### 1. Planning and Requirements

- Gather customer needs and feedback.
- Define project scope and objectives.
- Identify requirements and expected outcomes.

### 2. Defining and Designing

- Prepare the Software Requirements Specification (SRS).
- Create the High-Level Design (HLD).
- Create the Low-Level Design (LLD).
- Decide how the software will be structured and implemented.

### 3. Building (Development)

- Developers write application code.
- Code is stored and managed in a repository.
- Git helps track code changes and manage versions.

### 4. Testing

- The Quality Assurance (QA) team tests the application.
- Verify that the application meets requirements.
- Identify and fix bugs.
- Automated testing can help validate changes consistently.

### 5. Deployment

- Release the application to the production environment.
- Make the application available to end users.
- Deployment can be manual or automated.

## Role of DevOps in SDLC

DevOps improves collaboration between development and operations teams.

DevOps practices help automate and improve software delivery, especially building, testing, releasing, and deployment.

Examples include:

- Git for version control.
- CI pipelines for building and testing code.
- CD pipelines for delivering software.
- Monitoring tools for observing application health.

DevOps also supports feedback, reliability, and continuous improvement after deployment.

## Benefits of DevOps in SDLC

- Faster software delivery.
- Reduced manual work.
- More consistent deployments.
- Earlier detection of defects.
- Better collaboration.
- Improved reliability.

## Quick Revision

- **SDLC:** Software Development Life Cycle.
- **SRS:** Software Requirements Specification.
- **HLD:** High-Level Design.
- **LLD:** Low-Level Design.
- **Git:** Version control system.
- **QA:** Quality Assurance.
- **Production:** Environment where the application is available to users.

## Key Takeaway

SDLC defines the process of developing software. DevOps practices help teams collaborate, automate delivery, and improve how software is operated and maintained.
